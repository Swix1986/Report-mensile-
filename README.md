# TargetSales Pro

Applicazione web mobile (PWA) in Dark Mode per il monitoraggio dei target di vendita, storico mensile, giro visite, fuori giri di giornata, fido mensile rotativo, strategie di upselling, condivisione WhatsApp ed esportazione in formato Fogli (`.csv`).

## File inclusi nel pacchetto
- `index.html`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `.nojekyll`

## Come caricare su GitHub e pubblicare con GitHub Pages
1. Crea un nuovo repository su GitHub (es. `targetsales-pro`).
2. Estrai questo pacchetto `.ZIP` e carica tutti i file nella root del repository.
3. Vai su **Settings → Pages**.
4. In **Build and deployment**, imposta **Branch: `main`** e cartella **`/ (root)`**, quindi salva.
5. Apri l'URL `https://<tuo-username>.github.io/<nome-repo>/` sullo smartphone e aggiungila alla schermata Home.
